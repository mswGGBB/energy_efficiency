# 재학습 전/후 비교 보고서

※ 이 표는 `scripts/retrain_report.py` 가 만든 것입니다. 로그의 정답은 실제 사용자가 아니라 ResStock 데이터의 시뮬레이션 값이며, 요청은 정답을 아는 테스터(팀원 스크립트)가 보냈습니다.

## 0. 데이터 분할 (방식: random, seed 고정)

| 이름 | 건물 수 | 역할 |
|---|---|---|
| train | 26258 | 재학습 전 모델(v1)이 학습 |
| pool | 10940 | 서비스에 새로 들어올 건물. 테스트 요청·정답은 여기서만 나옴 |
| holdout | 6564 | 평가 전용. v1·v2 모두 학습하지 않음 |

## 1. 재학습에 쓴 로그 데이터 분석

- 로그 파일 1600행 → 중복 제거 1600행 → 학습에 쓸 수 있는 행: 상세 1600 / 간편 1600
- 요청 모드: {'detail': 1600}  / 응답한 모델 태그: {'v1': 1600}

**서비스가 낸 예측 vs 피드백으로 받은 정답** (재학습 전 모델이 이 건물들을 처음 본 결과)

| 대상 | MAE (MBtu) | 평균 편향 (예측-실제) | R² |
|---|---|---|---|
| 난방 | 7.48 | -0.14 | 0.944 |
| 냉방 | 4.25 | -0.04 | 0.917 |

- 분할 방식: random / 따로 보는 구간: 30평 미만 소형 주택
- 로그 중 30평 미만 소형 주택 비율: 25.4% (train 26.8%), 한랭 기후 비율: 7.4% (train 8.0%)
