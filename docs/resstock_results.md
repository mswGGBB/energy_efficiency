# ResStock 데이터 기반 냉난방 부하 모델 — 결과 정리

## 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 목표 | 추론 정확도 0.85 이상 (R² 0.85로 해석 — 기준 문구는 교수님 확인 필요) |
| 예측값 | 연간 난방 부하, 연간 냉방 부하 (MBtu/년, kWh로도 환산) |
| 데이터 | NREL ResStock 연간 기준 결과 (미국 주택 시뮬레이션, 약 55만 건) 중 8% 무작위 샘플 |

| 같은 기준으로 비교한 UCI 모델 | 건물 8개 조건 입력, 33~67평 범위 밖(20평대 등)은 예측 불가 |

## 2. 데이터

- 출처: ResStock: Annual Baseline Results with Component Loads (NREL, DOI 10.25984/2001060, 공개 데이터)
- 원본 `results_up00_update.csv` (1.43GB, 55만 행, 열 400여 개)에서 필요한 열만 골라 5만 행씩 나눠 읽고 행의 8%를 무작위로 추출 → 43,911행, 60개 열 (`scripts/extract_resstock_v2.py`)
- 학습에 쓴 표: 6,000 ft²(약 169평) 초과 대저택 149건을 뺀 **43,762행**, 면적 7.7~157평
- 원본 1.4GB 파일은 저장소에 올리지 않고, 추출한 샘플(`data/resstock_sample_v2.csv.gz`, 약 2.8MB)만 올림
- 이 데이터는 미국 주택과 미국 기상 데이터(TMY3)로 계산한 시뮬레이션 값이라, 한국 집에 그대로 맞는지는 검증되지 않음

## 3. 전처리 결정과 이유

| 처리 | 이유 |
|---|---|
| 면적을 ft² → 평으로 환산 (1평 = 35.58 ft²) | 서비스 입력 단위를 평으로 통일 |
| `occupants`의 `2`, `2.0`, `10+`을 숫자로 통일 | 같은 값이 문자열로 섞여 있어 오류·경고 발생 |
| `72F`, `15 ACH50`, `R-11` 같은 문자열에서 숫자만 추출 | 모델이 숫자로 계산할 수 있게 함 |
| 단열 `Uninsulated`와 빈칸은 R값 0 | 단열이 없거나 해당 구조가 없다는 뜻 |
| 설비·구조 빈칸은 `"None"` 범주로 채움 | 빈칸이 "오류"가 아니라 "그 설비/구조 없음"이라서 (예: 에어컨 없는 집) |
| 대저택(6,000 ft² 초과) 제외 | 극단값 149건이 학습을 흔듦 (난방 최대 2,875 MBtu) |
| `sample_weight` 제외 | 전부 같은 값(248.31)이라 정보 없음 |
| `report_simulation_output.*` 결과 열은 입력에서 제외 (부하 자체인 두 열만 정답으로 사용) | 시뮬레이션 **결과**를 입력으로 쓰면 예측 시점에 알 수 없는 정보가 들어가 점수만 부풀려짐 (데이터 누수) |
| 면적(ft²)당 부하를 학습한 뒤 면적을 곱해 총량으로 환산 | 집이 클수록 총량이 커지는 효과를 모델이 따로 배울 필요가 없게 함 |

### 점수를 크게 올린 발견: 설비 유무

1차 입력(설비 정보 없음)은 R² 난방 0.86 / 냉방 0.80이었다. 냉방 부하가 0인 집 6,981채 중 **99.1%가 에어컨이 없는 집**이었고(에어컨 없는 집 6,915채는 100% 냉방 0), 설비 정보를 추가하자 냉방 R²가 0.80 → 0.94로 올랐다. 처음에 설비 열을 "부하와 무관하다"고 판단해 뺀 것이 오류였고, 오차가 큰 집(부하 0인 집)을 분석해서 바로잡았다.

## 4. 모델과 평가 방법

- 알고리즘: `HistGradientBoostingRegressor` (난방, 냉방 각각 1개). 범주형은 `OrdinalEncoder` 후 범주형으로 직접 처리
- 평가: 전체의 20%(8,753건)를 학습에 쓰지 않고 따로 떼어 점수 계산 (`random_state=42`). 점수를 낸 뒤 배포용 모델은 전체로 다시 학습
- 지표: R²(설명력), MAE(평균 절대 오차, MBtu), 정확도 = 100 × (1 − 오차 합 ÷ 실제값 합)
- 단순 비교 기준: 항상 학습 평균값만 답하는 방식의 MAE

## 5. 결과

### 5-1. 전체 (검증 8,753건)

| 모드 | 타깃 | R² | MAE | 단순 기준 MAE | 정확도 |
|---|---|---|---|---|---|
| 상세 (27개 입력) | 난방 | **0.940** | 7.61 | 35.80 (79% 감소) | 82.8% |
| 상세 (27개 입력) | 냉방 | **0.919** | 4.19 | 17.42 (76% 감소) | 82.4% |
| 간편 (9개 입력) | 난방 | 0.734 | 16.05 | 35.80 (55% 감소) | 63.8% |
| 간편 (9개 입력) | 냉방 | 0.737 | 7.70 | 17.42 (56% 감소) | 67.8% |

### 5-2. 집 크기별 — 상세 모드 R² (난방 / 냉방)

| 구간 | 검증 건수 | R² | 정확도 |
|---|---|---|---|
| 10평 미만 | 304 | 0.853 / 0.874 | 75.1% / 80.5% |
| 10평대 | 767 | 0.888 / 0.874 | 77.4% / 80.0% |
| **20평대** | 1,226 | **0.906 / 0.896** | 79.2% / 82.2% |
| 30평대 | 2,251 | 0.919 / 0.903 | 82.4% / 82.2% |
| 40~59평 | 1,806 | 0.923 / 0.905 | 82.8% / 83.0% |
| 60평 이상 | 2,399 | 0.932 / 0.911 | 84.0% / 82.6% |

UCI 데이터(크기 4종류, 33~67평)에서 20평대가 예측되지 않던 문제는, 20평대 건물이 학습 데이터에 충분히(전체의 약 15%) 포함되면서 해결됐다.

### 5-3. 건물 유형별 — 상세 모드 R² (난방 / 냉방)

| 유형 | 검증 건수 | R² |
|---|---|---|
| 단독주택 | 5,419 | 0.937 / 0.917 |
| 이동식 주택 | 544 | 0.913 / 0.902 |
| 연립주택(Single-Family Attached) | 519 | 0.886 / 0.913 |
| 공동주택 2~4가구 | 690 | 0.892 / **0.829** |

## 6. 한계와 확인하지 못한 것

- **목표 기준**: "정확도 .85"를 R² 0.85로 읽었다. 정확도를 "100 − 오차 비율"로 보면 상세 모드는 82.8% / 82.4%로 **미달**이다.
- **간편 모드는 목표 미달**이다 (R² 0.73). 평수만으로는 기후·설비·단열을 알 수 없어 정확도가 낮다. 서비스에서는 "참고용"으로 표시해야 한다.
- **공동주택**(아파트에 가까운 유형)은 일부 R²가 0.85 미만이다 (5가구 이상 난방 0.844, 2~4가구 냉방 0.829). 한국 주거 형태와 가까운 구간이라 중요한 약점이다.
- 상세 모드 입력 27개 중 기밀도(ACH50), 벽·창 면적처럼 일반 사용자가 정확히 모르는 값이 있다. "외풍이 심한 편/보통" 같은 선택지로 바꿔 받으면 점수가 떨어질 수 있으나 아직 측정하지 않았다.
- 평가는 같은 샘플 안에서 무작위로 나눈 검증셋 기준이다. 미국 시뮬레이션 데이터라 한국 실측값과의 일치는 검증되지 않았다.
- 지역은 주(state)와 기후 구역으로 받는다. 위도·경도를 쓰면 R²가 0.02 정도 더 높았지만(0.957 / 0.942) 사용자가 알기 어려워 뺐다.
